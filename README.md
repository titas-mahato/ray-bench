# ray-bench

> Lightweight C++ graphics hardware benchmark built with Raylib.

`ray-bench` is a minimalist C++ graphics and hardware stress benchmark tailored for low-spec and budget hardware (specifically targeting an NVIDIA GeForce GTX 1650 and 8GB System RAM).

## Build and Run

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Run
```
